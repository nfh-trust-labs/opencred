# Verifiable Credentials Service

A core, unopinionated microservice for issuing and verifying verifiable credentials. Part of Trust Labs by Networks for Humanity.

## Overview

Template-based credential issuance. Designed as horizontally reusable infrastructure across Beckn One, Finternet, and DeDi.
