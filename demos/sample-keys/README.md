# Demo Issuer Key

**WARNING: This is a demo-only key. Do NOT use in production.**

This P-256 (ES256) keypair is provided for demonstration purposes only.
It is used in the desktop app demo for local credential signing.

## Usage

1. Open the desktop app: `cd apps/desktop && pnpm dev`
2. Navigate to Key Management
3. Import `demo-issuer.jwk`
4. Use the imported key to sign credentials
